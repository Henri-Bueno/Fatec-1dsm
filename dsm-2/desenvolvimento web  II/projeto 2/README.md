# Projeto 2

Aplicação de consulta de DDDs desenvolvida durante a disciplina de Desenvolvimento Web II.

## Objetivo

A interface permite consultar informações de códigos de área do Brasil, utilizando uma API externa e apresentação por contexto.

## Estrutura

- [app/front](./app/front)

## Tecnologias

- React
- TypeScript
- Vite
- API REST
- Context API

## Funcionalidades

- Busca de código de DDD
- Listagem de estados/regiões
- Contexto compartilhado para dados da aplicação
- Componentização da interface

## Execução

```bash
cd app/front
npm install
npm run dev
```
