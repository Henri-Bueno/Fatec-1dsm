# Aula 1

Aula introdutória de Desenvolvimento Web II com foco em front-end em React + TypeScript.

## Conteúdo

- Desenvolvimento de componentes em React
- Uso de TypeScript para tipagem de dados
- Renderização de listas e formulários
- Estrutura de projetos com Vite

## Local do projeto

- [app/front](./app/front)

## Principais arquivos

- [src/App.tsx](./app/front/src/App.tsx)
- [src/components/formulario.tsx](./app/front/src/components/formulario.tsx)
- [src/components/listaPessoas.tsx](./app/front/src/components/listaPessoas.tsx)

## Execução

```bash
cd app/front
npm install
npm run dev
```
