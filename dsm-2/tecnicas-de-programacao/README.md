# Técnicas de Programação

Disciplina do DSM 2 focada em fundamentos de programação, tipos em TypeScript e resolução de exercícios práticos.

## Conteúdo

- [Exercícios 1](./exercicios1)

## Objetivo

A disciplina trabalha conceitos como:

- tipagem estática
- `type` e `interface`
- união e interseção de tipos
- composição de objetos
- organização e execução de exercícios em TypeScript

## Execução

Os exercícios podem ser executados com os scripts do `package.json`, por exemplo:

```bash
cd exercicios1
npm install
npm run 1
```
