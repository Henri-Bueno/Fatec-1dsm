# Desenvolvimento Web

Disciplina do DSM 1 com exemplos de HTML e CSS, aplicações web com Express, interfaces interativas e projetos acadêmicos desenvolvidos ao longo das aulas.

## Projetos acadêmicos

| Projeto | Descrição |
| --- | --- |
| [Projeto 1 — Consulta de CEP](./Projeto%201) | Consulta um CEP na API ViaCEP e exibe os dados retornados. |
| [Projeto 2 — Sena Web App](./Projeto%202) | Cadastra e lista jogos de loteria usando uma API própria e PostgreSQL. |
| [Projeto 3 — Horários DSM](./Projeto%203) | Apresenta os horários das aulas dos seis semestres do DSM. |
| [Projeto 4 — Objetivos de Desenvolvimento Sustentável](./Projeto%204) | Apresenta os 17 ODS e permite alternar entre temas claro e escuro. |
| [Projeto 5 — Consulta da Mega-Sena](./Projeto%205) | Consulta concursos da Mega-Sena por meio de uma API e dados em PostgreSQL. |

## Demais atividades

- `aula 1`: exemplos introdutórios de HTML, formulários, seletores CSS, listas e Flexbox.
- `aula 2`: aplicação demonstrativa com páginas de início, login e cadastro, sem processamento real de autenticação.

Essas atividades foram mantidas com seus nomes originais por não constituírem aplicações funcionais completas no contexto analisado.
