# Projeto 3 — Horários DSM

## Visão geral

Projeto acadêmico desenvolvido durante a disciplina de Desenvolvimento Web. É uma página estática para consulta dos horários de aulas da graduação em Desenvolvimento de Software Multiplataforma.

## Funcionalidades

- Navegação por âncoras entre os seis semestres.
- Exibição dos horários de segunda a sexta-feira.
- Organização das disciplinas em tabelas por semestre.

## Tecnologias utilizadas

- HTML
- CSS
- Imagem PNG

## Pré-requisitos

- Navegador web

## Instalação

Não há dependências ou etapa de instalação. Os arquivos podem ser abertos diretamente no navegador.

## Como executar

Abra [`app/index.html`](./app/index.html) em um navegador.

## Scripts disponíveis

Este projeto não possui `package.json` nem scripts de execução.

## Estrutura do projeto

```text
Projeto 3/
└── app/
    ├── index.html
    ├── css/main.css
    └── img/logo_dsm_transparente.png
```

## Resultado

A página apresenta tabelas de horários e permite navegar entre os semestres por meio dos botões da própria interface.
